# 会话管理和知识库访问实现文档

## 一、项目概述

本子项目从 FuFan Chat API 中提取了会话管理和知识库访问的核心代码，作为一个独立的参考实现，供其他项目借鉴使用。

### 1.1 技术栈

- **Web框架**: FastAPI
- **数据库ORM**: SQLAlchemy (异步)
- **数据库**: MySQL 5.7+
- **向量数据库**: Faiss / Milvus
- **嵌入模型**: BGE-large-zh-v1.5
- **大语言模型**: ChatGLM / GLM-4 / OpenAI兼容接口
- **文档处理**: Unstructured, LangChain
- **重排序**: BGE Reranker

## 二、会话管理实现

### 2.2 关键实现细节

#### 2.2.1 异步会话管理

```python
@asynccontextmanager
async def async_session_scope():
    """异步数据库会话上下文管理器"""
    session = AsyncSessionLocal()
    try:
        yield session
        await session.commit()
    except Exception as e:
        await session.rollback()
        raise e
    finally:
        await session.close()

def with_async_session(f):
    """装饰器：自动管理数据库会话"""
    @wraps(f)
    async def wrapper(*args, **kwargs):
        async with async_session_scope() as session:
            return await f(session, *args, **kwargs)
    return wrapper
```

**优势**：
- 自动处理会话生命周期
- 异常时自动回滚
- 减少代码重复

#### 2.2.3 历史记录加载与截断

```python
async def buffer(self) -> List[BaseMessage]:
    """加载并处理历史消息"""
    # 1. 从数据库加载最近N条消息
    messages = await filter_message(
        conversation_id=self.conversation_id,
        limit=self.message_limit,
        chat_type=self.chat_type
    )
    messages = list(reversed(messages))
    
    # 2. 转换为LangChain消息格式
    chat_messages: List[BaseMessage] = []
    for message in messages:
        chat_messages.append(HumanMessage(content=message.query))
        chat_messages.append(AIMessage(content=message.response))
    
    # 3. Token数量控制
    curr_buffer_length = self.llm.get_num_tokens(get_buffer_string(chat_messages))
    if curr_buffer_length > self.max_token_limit:
        while curr_buffer_length > self.max_token_limit and chat_messages:
            chat_messages.pop(0)  # 移除最早的消息
            curr_buffer_length = self.llm.get_num_tokens(get_buffer_string(chat_messages))
    
    return chat_messages
```

**智能截断策略**：
- 优先保留最近的对话
- 动态计算Token数量
- 避免超出模型上下文长度限制

## 三、知识库访问实现

**MilvusKBService**: Milvus实现
- 分布式向量数据库
- 适合大规模应用

**KBServiceFactory**: 工厂类
- 统一服务创建入口
- 服务实例缓存
- 支持按名称自动加载配置

### 3.2 关键实现细节

#### 3.2.1 工厂模式实现

```python
class KBServiceFactory:
    _services = {}
    
    @classmethod
    async def get_service(cls, kb_name: str, vs_type: str, embed_model: str):
        """获取或创建知识库服务"""
        key = f"{kb_name}_{vs_type}_{embed_model}"
        
        if key not in cls._services:
            if vs_type == SupportedVSType.FAISS:
                service = FaissKBService(kb_name, embed_model)
            elif vs_type == SupportedVSType.MILVUS:
                service = MilvusKBService(kb_name, embed_model)
            else:
                raise ValueError(f"不支持的向量库类型: {vs_type}")
            
            cls._services[key] = service
        
        return cls._services[key]
    
    @classmethod
    async def get_service_by_name(cls, kb_name: str):
        """根据知识库名称加载配置"""
        kb_name, vs_type, embed_model = await load_kb_from_db(kb_name)
        if kb_name is None:
            return None
        return await cls.get_service(kb_name, vs_type, embed_model)
```

**优势**：
- 统一的创建接口
- 实例复用，节省资源
- 易于扩展新类型

#### 3.2.2 文档处理流程

```python
class KnowledgeFile:
    def file2text(self):
        """文档加载和切分"""
        # 1. 选择文档加载器
        if self.ext == ".pdf":
            loader = UnstructuredPDFLoader(self.filepath)
        elif self.ext == ".md":
            loader = UnstructuredMarkdownLoader(self.filepath)
        elif self.ext == ".txt":
            loader = TextLoader(self.filepath, encoding='utf-8')
        
        # 2. 加载文档
        docs = loader.load()
        
        # 3. 文本切分
        text_splitter = ChineseTextSplitter(
            chunk_size=250,
            chunk_overlap=50
        )
        split_docs = text_splitter.split_documents(docs)
        
        return split_docs
```

**处理策略**：
- 根据文件类型自动选择loader
- 智能文本切分保持语义完整
- 支持中文标点和段落识别

#### 3.2.3 向量检索实现

```python
async def search_docs(
    query: str,
    knowledge_base_name: str,
    top_k: int,
    score_threshold: float
):
    """向量检索"""
    # 1. 获取知识库服务
    kb_service = await KBServiceFactory.get_service_by_name(knowledge_base_name)
    
    # 2. 向量检索
    docs = kb_service.do_search(
        query=query,
        top_k=top_k,
        score_threshold=score_threshold
    )
    
    # 3. 可选：Reranker重排序
    if USE_RERANKER:
        reranker = LangchainReranker(top_n=RERANKER_TOP_K, ...)
        docs = reranker.compress_documents(documents=docs, query=query)
    
    return docs
```

**检索优化**：
- 相似度阈值过滤
- Reranker精排
- 返回相关度最高的文档

#### 3.2.4 与对话系统集成

```python
async def knowledge_base_chat(query, conversation_id, knowledge_base_name, ...):
    """知识库问答"""
    # 1. 检索相关文档
    docs = await search_docs(
        query=query,
        knowledge_base_name=knowledge_base_name,
        top_k=top_k
    )
    
    # 2. 构建上下文
    context = "\n\n".join([doc.page_content for doc in docs])
    
    # 3. 加载对话历史
    memory = ConversationBufferDBMemory(
        conversation_id=conversation_id,
        llm=model,
        chat_type=prompt_name,
        message_limit=10
    )
    
    # 4. 构建Prompt并生成回答
    prompt = f"基于以下上下文回答问题：\n{context}\n\n问题：{query}"
    chain = LLMChain(prompt=prompt, llm=model, memory=memory)
    
    # 5. 流式返回
    async for token in chain.astream({"input": query}):
        yield token
```

**整合要点**：
- 检索增强生成（RAG）
- 历史对话支持多轮问答
- 流式输出提升体验

### 4.2 索引设计

**优化查询性能的关键索引**：

1. **用户相关查询**
   - `idx_user_id` on conversation(user_id)
   - `idx_user_id` on knowledge_base(user_id)
   - 加速按用户过滤的查询

2. **会话消息查询**
   - `idx_conversation_id` on message(conversation_id)
   - 加速获取会话历史

3. **时间排序查询**
   - `idx_create_time` on conversation(create_time)
   - `idx_create_time` on message(create_time)
   - 加速按时间排序

4. **知识库文件查询**
   - `idx_kb_name` on knowledge_file(kb_name)
   - `idx_kb_file` on file_doc(kb_name, file_name)
   - 加速知识库文件列表查询

5. **唯一约束**
   - `UNIQUE(username)` on user
   - `UNIQUE(user_id, kb_name)` on knowledge_base
   - 防止重复数据
