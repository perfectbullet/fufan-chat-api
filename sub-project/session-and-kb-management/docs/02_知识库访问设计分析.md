# 知识库访问设计分析

## 一、概述

FuFan Chat API 的知识库访问系统基于 RAG (Retrieval-Augmented Generation) 架构，整合了向量数据库（Faiss、Milvus）、文档处理、嵌入模型和大语言模型，实现了高效的私有知识库问答功能。系统支持多用户、多知识库、多文件格式，并提供了完整的知识库生命周期管理。

## 二、核心设计理念

### 2.1 设计目标

1. **用户隔离**：每个用户拥有独立的知识库空间，确保数据安全和隐私
2. **多向量库支持**：支持 Faiss、Milvus 等多种向量数据库
3. **灵活的文档处理**：支持 PDF、Markdown、TXT 等多种文档格式
4. **高效检索**：结合向量检索和重排序（Reranker）提升检索精度
5. **可扩展架构**：工厂模式+抽象基类，易于扩展新的向量库类型

### 2.2 架构特点

- **三层存储架构**：MySQL元数据 + 向量数据库索引 + 文件系统存储
- **工厂模式**：KBServiceFactory统一管理不同类型的知识库服务
- **抽象基类**：KBService定义统一接口，具体实现类（FaissKBService、MilvusKBService）
- **异步处理**：文档加载、向量化、检索全流程异步化
- **检索增强**：集成Reranker模型进行结果重排序

## 四、知识库服务架构

### 4.1 抽象基类（KBService）

```python
class KBService(ABC):
    def __init__(self, knowledge_base_name: str, embed_model: str = EMBEDDING_MODEL):
        self.kb_name = knowledge_base_name
        self.kb_info = KB_INFO.get(knowledge_base_name, f"关于{knowledge_base_name}的知识库")
        self.embed_model = embed_model
        self.kb_path = get_kb_path(self.kb_name)
        self.doc_path = get_doc_path(self.kb_name)
        self.do_init()
    
    @abstractmethod
    def vs_type(self) -> str:
        """返回向量库类型"""
        pass
    
    @abstractmethod
    def do_create_kb(self):
        """创建知识库"""
        pass
    
    @abstractmethod
    def do_add_doc(self, docs: List[Document], **kwargs):
        """添加文档到向量库"""
        pass
    
    @abstractmethod
    def do_delete_doc(self, kb_file: KnowledgeFile, **kwargs):
        """从向量库删除文档"""
        pass
    
    @abstractmethod
    def do_search(self, query: str, top_k: int, score_threshold: float):
        """向量检索"""
        pass
```

**设计优势**：
- 定义统一接口，规范各种向量库的操作
- 抽象方法强制子类实现核心功能
- 通用逻辑（文件管理、元数据更新）在基类实现

### 4.2 工厂模式（KBServiceFactory）

```python
class KBServiceFactory:
    _services = {}  # 缓存已创建的服务实例
    
    @classmethod
    async def get_service(cls, 
                         knowledge_base_name: str,
                         vector_store_type: str,
                         embed_model: str) -> KBService:
        """根据参数创建或获取知识库服务"""
        key = f"{knowledge_base_name}_{vector_store_type}_{embed_model}"
        
        if key not in cls._services:
            if vector_store_type == SupportedVSType.FAISS:
                service = FaissKBService(knowledge_base_name, embed_model)
            elif vector_store_type == SupportedVSType.MILVUS:
                service = MilvusKBService(knowledge_base_name, embed_model)
            else:
                raise ValueError(f"不支持的向量库类型: {vector_store_type}")
            
            cls._services[key] = service
        
        return cls._services[key]
    
    @classmethod
    async def get_service_by_name(cls, knowledge_base_name: str) -> KBService:
        """根据知识库名称从数据库加载配置并创建服务"""
        kb_name, vs_type, embed_model = await load_kb_from_db(knowledge_base_name)
        if kb_name is None:
            return None
        return await cls.get_service(kb_name, vs_type, embed_model)
```

**设计优势**：
- 统一的服务创建入口
- 服务实例缓存，避免重复创建
- 支持按名称自动加载配置
- 易于扩展新的向量库类型

### 4.3 Faiss知识库服务（FaissKBService）

Faiss是Facebook开源的高效相似度搜索库，适合本地部署：

```python
class FaissKBService(KBService):
    vs_type = SupportedVSType.FAISS
    
    def do_init(self):
        self.vector_store_path = os.path.join(self.kb_path, "vector_store")
        
    def do_create_kb(self):
        """创建空的Faiss索引"""
        if not os.path.exists(self.vector_store_path):
            os.makedirs(self.vector_store_path)
    
    async def do_add_doc(self, docs: List[Document], **kwargs):
        """添加文档到Faiss索引"""
        # 1. 文档向量化
        embeddings_dict = self._docs_to_embeddings(docs)
        embeddings = embeddings_dict["embeddings"]
        
        # 2. 加载或创建Faiss索引
        if os.path.exists(os.path.join(self.vector_store_path, "index.faiss")):
            vector_store = FAISS.load_local(self.vector_store_path, embeddings_model)
        else:
            vector_store = FAISS.from_documents(docs, embeddings_model)
        
        # 3. 添加向量到索引
        doc_ids = vector_store.add_documents(docs)
        
        # 4. 保存索引
        vector_store.save_local(self.vector_store_path)
        
        return doc_ids
    
    def do_search(self, query: str, top_k: int, score_threshold: float):
        """相似度检索"""
        vector_store = FAISS.load_local(self.vector_store_path, embeddings_model)
        docs = vector_store.similarity_search_with_score(query, k=top_k)
        
        # 过滤低分文档
        filtered_docs = [
            (doc, score) for doc, score in docs 
            if score >= score_threshold
        ]
        
        return filtered_docs
```

**实现特点**：
- 本地文件存储，无需额外服务
- 支持增量添加文档
- 相似度阈值过滤
- 高效的向量检索性能

### 4.4 Milvus知识库服务（MilvusKBService）

Milvus是专业的分布式向量数据库，适合大规模部署：

```python
class MilvusKBService(KBService):
    vs_type = SupportedVSType.MILVUS
    
    def do_init(self):
        self.collection_name = self.kb_name
        self.milvus_client = Milvus(host=MILVUS_HOST, port=MILVUS_PORT)
    
    def do_create_kb(self):
        """创建Milvus集合"""
        if self.collection_name not in self.milvus_client.list_collections():
            # 定义集合schema
            fields = [
                FieldSchema(name="id", dtype=DataType.INT64, is_primary=True, auto_id=True),
                FieldSchema(name="embedding", dtype=DataType.FLOAT_VECTOR, dim=1024),
                FieldSchema(name="text", dtype=DataType.VARCHAR, max_length=65535),
            ]
            schema = CollectionSchema(fields, description="Knowledge base collection")
            self.milvus_client.create_collection(self.collection_name, schema)
            
            # 创建索引
            index_params = {
                "index_type": "IVF_FLAT",
                "metric_type": "IP",  # 内积
                "params": {"nlist": 1024}
            }
            self.milvus_client.create_index(self.collection_name, "embedding", index_params)
    
    async def do_add_doc(self, docs: List[Document], **kwargs):
        """添加文档到Milvus"""
        embeddings_dict = self._docs_to_embeddings(docs)
        
        entities = [
            {"embedding": emb, "text": doc.page_content}
            for emb, doc in zip(embeddings_dict["embeddings"], docs)
        ]
        
        insert_result = self.milvus_client.insert(self.collection_name, entities)
        return insert_result.primary_keys
    
    def do_search(self, query: str, top_k: int, score_threshold: float):
        """向量检索"""
        query_embedding = embed_texts([query], self.embed_model)[0]
        
        search_params = {"metric_type": "IP", "params": {"nprobe": 10}}
        results = self.milvus_client.search(
            collection_name=self.collection_name,
            data=[query_embedding],
            anns_field="embedding",
            param=search_params,
            limit=top_k
        )
        
        return results
```

**实现特点**：
- 分布式架构，支持海量数据
- 自动ID生成
- 多种索引类型（IVF_FLAT、HNSW等）
- 支持多种距离度量（内积、欧氏距离等）

## 五、文档处理流程

### 5.1 文档加载

支持多种文档格式的加载：

```python
class KnowledgeFile:
    def __init__(self, filename: str, knowledge_base_name: str):
        self.kb_name = knowledge_base_name
        self.filename = filename
        self.filepath = get_file_path(knowledge_base_name, filename)
        self.ext = os.path.splitext(filename)[-1].lower()
    
    def file2text(self, using_zh_title_enhance: bool = True):
        """文档加载和文本切分"""
        # 1. 根据文件类型选择加载器
        if self.ext == ".pdf":
            loader = UnstructuredPDFLoader(self.filepath)
        elif self.ext == ".md":
            loader = UnstructuredMarkdownLoader(self.filepath)
        elif self.ext == ".txt":
            loader = TextLoader(self.filepath, encoding='utf-8')
        else:
            raise ValueError(f"不支持的文件格式: {self.ext}")
        
        # 2. 加载文档
        docs = loader.load()
        
        # 3. 文本切分
        text_splitter = ChineseTextSplitter(
            chunk_size=250,
            chunk_overlap=50
        )
        split_docs = text_splitter.split_documents(docs)
        
        # 4. 中文标题增强（可选）
        if using_zh_title_enhance:
            split_docs = self._zh_title_enhance(split_docs)
        
        return split_docs
```

**处理流程**：
1. 根据文件扩展名选择合适的DocumentLoader
2. 加载文档获取原始文本
3. 使用TextSplitter切分文档为小块
4. 可选的中文标题增强处理

### 5.2 文档切分策略

```python
class ChineseTextSplitter(TextSplitter):
    def __init__(self, chunk_size: int = 250, chunk_overlap: int = 50):
        super().__init__(chunk_size=chunk_size, chunk_overlap=chunk_overlap)
        self.chunk_size = chunk_size
        self.chunk_overlap = chunk_overlap
    
    def split_text(self, text: str) -> List[str]:
        """智能文本切分"""
        # 1. 按段落切分
        paragraphs = re.split(r'\n\n+', text)
        
        chunks = []
        current_chunk = ""
        
        for para in paragraphs:
            # 2. 如果段落太长，按句子切分
            if len(para) > self.chunk_size:
                sentences = re.split(r'[。！？\n]', para)
                for sent in sentences:
                    if len(current_chunk) + len(sent) > self.chunk_size:
                        if current_chunk:
                            chunks.append(current_chunk)
                        current_chunk = sent
                    else:
                        current_chunk += sent
            else:
                if len(current_chunk) + len(para) > self.chunk_size:
                    if current_chunk:
                        chunks.append(current_chunk)
                    current_chunk = para
                else:
                    current_chunk += para
        
        if current_chunk:
            chunks.append(current_chunk)
        
        return chunks
```

**切分策略**：
- 优先按段落切分，保持语义完整
- 段落过长时按句子切分
- chunk_overlap保证上下文连贯性
- 适配中文标点符号

```python
def embed_documents(docs: List[Document], embed_model: str, to_query: bool = False):
    """文档向量化"""
    texts = [doc.page_content for doc in docs]
    
    # 调用嵌入模型API
    embeddings = embedding_api.embed_texts(
        texts=texts,
        model=embed_model,
        to_query=to_query
    )
    
    return {
        "embeddings": embeddings,
        "documents": docs
    }

async def aembed_texts(texts: List[str], embed_model: str, to_query: bool = False):
    """异步文本向量化"""
    # 批量处理，提升效率
    batch_size = 32
    all_embeddings = []
    
    for i in range(0, len(texts), batch_size):
        batch = texts[i:i+batch_size]
        embeddings = await embedding_api.aembed_texts(
            texts=batch,
            model=embed_model,
            to_query=to_query
        )
        all_embeddings.extend(embeddings)
    
    return all_embeddings
```

**向量化特点**：
- 支持同步和异步两种模式
- 批量处理提升效率
- to_query参数区分文档向量和查询向量
- 支持多种嵌入模型（bge-large-zh-v1.5等）

### 6.2 重排序（Reranker）

在向量检索基础上，使用Reranker模型进行结果重排序：

```python
async def search_docs_with_rerank(
    query: str,
    knowledge_base_name: str,
    top_k: int = VECTOR_SEARCH_TOP_K,
    score_threshold: float = SCORE_THRESHOLD,
    rerank_top_k: int = 3
) -> List[Document]:
    """带重排序的检索"""
    # 1. 向量检索（召回更多候选）
    docs = await search_docs(
        query=query,
        knowledge_base_name=knowledge_base_name,
        top_k=top_k * 2,  # 召回更多候选
        score_threshold=score_threshold
    )
    
    if not docs or not USE_RERANKER:
        return docs[:top_k]
    
    # 2. Reranker重排序
    reranker_model_path = get_model_path(RERANKER_MODEL)
    reranker = LangchainReranker(
        top_n=rerank_top_k,
        device=embedding_device(),
        max_length=RERANKER_MAX_LENGTH,
        model_name_or_path=reranker_model_path
    )
    
    # 3. 重排序
    reranked_docs = reranker.compress_documents(
        documents=docs,
        query=query
    )
    
    return reranked_docs
```

**Reranker优势**：
- 提升检索精度，尤其是Top-3的准确率
- 基于Cross-Encoder架构，考虑query和doc的交互
- 可配置是否启用，灵活控制

async def create_knowledge_base(
    request: CreateKnowledgeBaseRequest,
    session: AsyncSession = Depends(get_async_db)
):
    """创建知识库"""
    # 1. 验证知识库名称
    if request.knowledge_base_name.strip() == "":
        return {"msg": "知识库名称不能为空"}
    
    # 2. 检查是否已存在
    existing_kb = await session.execute(
        select(KnowledgeBaseModel)
        .where(
            KnowledgeBaseModel.kb_name == request.knowledge_base_name,
            KnowledgeBaseModel.user_id == request.user_id
        )
    )
    if existing_kb.scalars().first() is not None:
        return {"msg": f"已存在同名知识库 {request.knowledge_base_name}"}
    
    # 3. 创建数据库记录
    new_kb = KnowledgeBaseModel(
        kb_name=request.knowledge_base_name,
        kb_info=request.knowledge_base_description,
        vs_type=request.vector_store_type,
        embed_model=request.embed_model,
        user_id=request.user_id
    )
    session.add(new_kb)
    await session.commit()
    
    # 4. 创建知识库服务（文件目录和向量库）
    kb_service = await KBServiceFactory.get_service(
        knowledge_base_name=request.knowledge_base_name,
        vector_store_type=request.vector_store_type,
        embed_model=request.embed_model
    )
    kb_service.create_kb()
    
    return {"msg": f"已新增知识库 {request.knowledge_base_name}"}
```

async def upload_file_to_kb(

    await kb_service.add_doc(kb_file, docs)
    
    # 5. 更新数据库
    await add_file_to_db(kb_file, custom_docs=False, docs_count=len(docs))
    
    return {"msg": f"文件 {file.filename} 添加成功"}
```

async def delete_knowledge_base(
    request: DeleteKnowledgeBaseRequest,
    session: AsyncSession = Depends(get_async_db)
):
    """删除知识库"""
    # 1. 查找知识库
    kb = await session.execute(
        select(KnowledgeBaseModel)
        .where(
            KnowledgeBaseModel.kb_name == request.knowledge_base_name,
            KnowledgeBaseModel.user_id == request.user_id
        )
    )
    kb = kb.scalars().first()
    if kb is None:
        return {"msg": f"未找到知识库 {request.knowledge_base_name}"}
    
    # 2. 删除向量库
    kb_service = await KBServiceFactory.get_service_by_name(request.knowledge_base_name)
    kb_service.drop_kb()
    
    # 3. 删除数据库记录
    await session.delete(kb)
    await session.commit()
    
    return {"msg": f"成功删除知识库 {request.knowledge_base_name}"}
```

    """知识库问答"""
    # 1. 获取知识库服务
    kb = await KBServiceFactory.get_service_by_name(knowledge_base_name)
    if kb is None:
        return {"error": f"未找到知识库 {knowledge_base_name}"}
    
    # 2. 创建消息记录
    message_id = await add_message_to_db(
        conversation_id=conversation_id,
        prompt_name=prompt_name,
        query=query
    )
    
    # 3. 检索相关文档
    docs = await search_docs(
        query=query,
        knowledge_base_name=knowledge_base_name,
        top_k=top_k,
        score_threshold=SCORE_THRESHOLD
    )
    
    # 4. 重排序（如果启用）
    if USE_RERANKER:
        reranker = LangchainReranker(top_n=RERANKER_TOP_K, ...)
        docs = reranker.compress_documents(documents=docs, query=query)
    
    # 5. 构建上下文
    context = "\n\n".join([doc.page_content for doc in docs])
    
    # 6. 加载对话历史
    memory = ConversationBufferDBMemory(
        conversation_id=conversation_id,
        llm=model,
        chat_type=prompt_name,
        message_limit=10
    )
    
    # 7. 构建Prompt
    prompt_template = get_prompt_template(prompt_name, "knowledge_base_chat")
    prompt = prompt_template.format(context=context, question=query)
    
    # 8. 调用LLM生成回答
    chain = LLMChain(prompt=prompt, llm=model, memory=memory)
    async for token in chain.astream({"input": query}):
        yield json.dumps({"text": token, "message_id": message_id})
```

**流程特点**：
- 先检索后生成（RAG范式）
- 整合对话历史，支持多轮问答
- 流式返回，提升用户体验
- 自动记录消息和元数据
